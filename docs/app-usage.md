# 应用使用统计

“使用统计”页记录有效桌面会话中的前台应用停留时间；有效活跃时间仅取输入空闲阈值以内的部分，默认 120 秒。阅读、视频或辅助输入可能导致空闲判断与实际使用不同，两项指标分开显示。首次启动仍暂停；设置可关闭此模块、调整阈值和保留天数、排除 EXE 名或完整路径、关闭图标。

- 使用独立隐藏消息窗口、前台 WinEvent 通知和每秒状态检查；没有键盘 Hook、输入注入或窗口标题读取。[Microsoft WinEvent 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwineventhook)说明异步通知需要消息循环，因此前台边界仍有通知延迟，不承诺逐毫秒归属精度。
- 计时来自单调时钟，按 UTC 分钟拆桶；本地日历日期用于页面汇总。超过 2.5 秒的采样缺口、睡眠跳变或明显系统时钟变更不补算，并显示缺口计数。会话锁定、断开、休眠和不受支持的输入桌面停止累计；恢复重新建立基线。暂停/配置边界保守舍弃尚未结算的短间隔，通常不超过一秒。
- [GetLastInputInfo](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getlastinputinfo)仅反映当前会话且时间值不保证单调；反常值不追加活跃时间。通知注册失败时不采集。应用身份使用经创建时间检查的存活进程句柄取得的 EXE 路径；同路径多进程聚合，保护进程无法解析时单列未知。Windows 宿主/共享进程不推断内部应用。
- 仅保存应用标识、名称、路径和分钟聚合时长，不保存窗口标题、文档、URL、输入或逐次切换历史。输入路径独立于 Raw Input 和数据库线程。SQLite 按现有刷新周期批量 UPSERT，异常退出可能丢失最近未提交的一个刷新周期；不补算关闭期间时间。
- Schema 4→5 使用现有 Online Backup 和事务迁移，添加 `app_usage` 表及时间/身份索引；原有键鼠、网络、月档和配置保留。旧版程序应使用迁移前备份，不能直接写 v5 库。全局清除同时移除使用统计；导出按钮生成独立 CSV。

## 实际验证与限制

Release/Debug 构建；52 项时间模型、空闲恢复、跨分钟/跨日、暂停、缺口、数据库迁移/备份/回滚、重启、CSV、清除与配置检查，8 项前端聚合检查。原生 WebView2 使用统计页面、七页×两语言×深浅主题布局和关闭释放重开检查已通过；开启采集的隔离运行确实显示真实前台 EXE 及图标，截图保存在忽略的 build 目录，不公开个人统计。

独立 `app_usage_native_probe.exe` 创建两个受控应用尝试前台切换；本环境 Windows 拒绝 `SetForegroundWindow`，该场景**未通过**，不能当作双应用归属验收。没有注入输入或绕过系统前台权限。可从用户主动打开的终端执行此工具；若仍受限，请手动切换两个应用检查排行榜。真实锁屏/解锁、休眠/唤醒、注销/会话切换、PID 复用压力和长时间 CPU/内存仍待人工验收；不会为测试而锁定用户会话或触发系统休眠。

人工复测：暂停→选择 15 秒阈值→开始→在 A 输入并停留 20 秒→切换 B 输入并停留 5 秒→暂停。A 停留约 20 秒、活跃至多约 15 秒，B 单独累计；后台 A 不应继续增长。然后排除 A、恢复采集、手动锁屏/解锁及休眠/唤醒，核对未补算离开时段。完全退出后重开，检查历史和配置；在测试数据副本上执行导出/清除。
