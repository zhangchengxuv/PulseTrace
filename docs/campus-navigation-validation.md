# 校园网与页面切换回归（2026-11-06）

本轮使用独立测试目录、合成门户和本机 Windows WebView2，未读取用户数据库或登录真实高校账号。数据库 schema 不变，旧配置默认按 GiB 单价解释。

## 校园网

- DOM 测试覆盖表格、卡片、定义列表；GB/GiB、千位分隔、小写单位、隐藏值、登录页、失效选择器和歧义。
- 原生 WebView2 本地 HTTP 门户验证手动点选、规则立即切换、服务器余额变化后重新获取。
- 存储测试验证全部 11 字段、v6→v7 兼容迁移、原始统计保留、GB 单价持久化及不支持单位拒绝。
- 计算测试验证免费与普通额度分离、免费优先分配需明确确认、已扣费余额不重复扣减、缺失账期、零单价、缺失数据及旧公式兼容。
- 设置交互测试验证候选明确确认、计费编辑不隐式确认候选、保存失败阻止打开门户。普通界面不提供公式输入。
- 原生 800×600 中文 Deep Ocean、1600×900 英文 Pearl Mist 截图已查看；自检遍历双语、双主题和七页检查横向溢出。当前桌面 DPI 125%，不代表其他 DPI 或显示器。

## 页面切换

原有原子 DOM 替换保留。本轮消除等待 RPC 才切页及下一帧才恢复滚动的路径；按页面最多保留七组 DOM、图表观察器和页面数据。配置/语言变化会使旧缓存失效。后台刷新数据未变时复用内容，页面离开后图表不绘制；返回时原观察器恢复绘制。

公共侧栏和工具栏节点保留，只对内容区做 150 ms 淡入。系统减少动态效果时禁用淡入。首访页面先展示空数据视图和加载提示，异步查询不阻塞切页；不会把上一页面的统计行放进新页面。滚动条预留空间，滚动恢复在内容替换的同一任务完成。

原生自检连续切换七页 28 次，其中 21 次复用已访问节点；检查公共节点身份、表单草稿、筛选范围、图表重新挂载绘制和减少动态效果。每次切换后采样内容，空 DOM 帧为 0。一个隔离运行的同步切页 DOM 时间均值 **3.37 ms**、P95 **5.20 ms**；这是 JavaScript/DOM 时间，不是 GPU 呈现延迟或显示器 FPS。

一次隔离 Release 自检的进程树采样共 **44** 点、约 **18.87 s**，包括启动、双语/主题布局检查、两次 WebView 打开/关闭和退出：12 逻辑核归一化 CPU 均值 **0.83%**、采样峰值 **19.59%**；主程序与所观察 WebView 子进程 Private Bytes 合计均值 **247.87 MiB**、峰值 **414.66 MiB**，进程峰值 **7**。这不是稳态导航开销，也没有同条件旧版基线，不能据此声称 CPU/内存降低。原始数据只留在忽略的 build 目录。
