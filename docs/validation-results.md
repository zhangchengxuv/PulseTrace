# 实际验证结果

> 本文件保留 MouseMonitor MVP 时的真实检查点。当前桌面集成与新增测试请参阅 desktop-validation-results.md；下文“尚未实现/验证”不代表当前版本全部状态。

记录日期：2026-11-04（用户时区 Asia/Singapore）。仅报告本次实际执行项目，不把设计目标记为通过。

环境：Microsoft Windows 11 Pro，10.0.26300；LLVM-MinGW 20260616 / Clang 22.1.8，x64 UCRT；CMake 3.31.8。没有使用 MSVC，也未完成其他 Windows 版本的兼容性测试。

## 已执行

| 项目 | 结果与限制 |

| Debug CMake 编译 + CTest | 通过，同一组检查；不依赖 Release 下可能移除的 assert |

| 最终版本键鼠共享注册 3 秒烟测 | `--keyboard-count` 成功完成双设备类注册、定时结束、显式注销和报告输出；同样没有真实输入包，不作为并发输入性能结果 |
| 输入校验 | 过大保留窗口在开始采集前拒绝；准确性比较工具正确拒绝零包捕获报告 |

## 尚未验证

- 高频物理 HID 点击事件丢失率、真实滚轮增量与连续事件准确性；需要独立硬件真值。
- 物理/合成/触控板来源的可用覆盖范围与具体设备差异；没有声称已可靠三分。
- 回调耗时与 Raw Input 队列延迟分布；烟测没有输入包，零值无结论。
- 端到端鼠标操作延迟；已提供可编译的颜色翻转目标，但尚未用外部仪器完成 A/B 测量。
- 键鼠同时高频物理输入 CPU；当前只提供共享线程测试入口，没有发生器结果。
- 24/72 小时实机内存、热插拔、睡眠恢复、系统双击设置变更和实际 Ctrl+C 人工测试。
- Windows 10、其他 Windows 11 构建、MSVC、MinGW GCC、虚拟/远程桌面兼容性。
- SQLite、HTTP API、Web 可视化、写失败恢复、原有键盘与网络模块回归；当前无既有代码且尚未进入集成阶段。

## 已知边界

时间双击不是 Windows 空间双击；空设备句柄不识别双击；状态表超过 64 个设备/来源组合时退化并报告；只精确查询分钟边界；UTC 天不同于本地日历天；异常退出丢失本次验证会话内存统计。所有这些限制都应在产品化时继续明确展示。
