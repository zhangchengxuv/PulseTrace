# PulseTrace 开发状态

当前阶段：H，0.2.0-rc1 候选版本已生成，完成当前普通权限环境内的构建、自动化集成、进程资源及独立部署验证；完整最终验收未通过，外部限制和未实现项如下。

已实现并通过构建及集成自检：Win32/WebView2、官方 Loader 动态加载、本地虚拟来源、受限 JSON 消息、托盘隐藏/重开/退出、独立 CoreService 输入线程、扫描码键盘聚合、复用 MouseMonitor、SQLite WAL/事务/迁移/历史查询、网络接口总量/来源识别、配置与数据清理接口。六页桌面前端使用真实核心/数据库数据，空库显示空状态。

已完成运行验证：初始化中关闭、浏览器进程故障恢复、六页逐页截图、缺 Loader/缺资源的预期失败、无效数据目录拒绝、发布 ZIP 独立解压运行、带空格路径安装复制后运行。现有 HTTP 报告原型不作为桌面运行依赖。

已补齐：Network List Manager 系统 IPv4/IPv6 连通性提示（不冒充单接口主动可达性证明）；网络连接观察历史表；SQLite schema v2；异常事务退出恢复；写锁导致最终提交失败时保留聚合，并可在取消退出/排除问题后再次提交；原生版本/DPI manifest；手动目录选择；只在用户设置触发时才写自启动项；有界日志；安装与打包脚本，已部署自检。最后审查修复配置整数转换溢出、无效持久化主题、Windows 参数尾部反斜杠转义与目录选择失败检查，并通过新增测试。

未完成/外部条件：精确 IPv4/IPv6 分项后端尚未实现；权限探测 StartTraceW 实际返回 5 (ACCESS_DENIED)，当前明确显示未支持，不升权或改系统组权限。高频 HID/摄像测延迟、Windows 10/其他 Windows 11、24/72 小时、Clash TUN 开关对照及真实自启动登录验收待人工/外部环境。故未达到全部最终验收标准。

编译/测试：最终修复后的 Release 和 Debug 完整构建成功，各 CTest 3/3（56 项原鼠标检查 + 108 项产品检查 + 实际 WebView2 生命周期）。此前 20 次 UI 重开循环、六页逐页自检、渲染函数自检通过。内部 PNG 截图成功并已查看总览、键盘和设置。发布/安装副本自检均返回 0；ZIP 文件哈希和无运行数据夹带检查通过。

资源验证发现并修复过退出问题：初版主进程退出时两名子进程仍未退出；现在主消息泵等待 BrowserProcessExited，最终复测无已观察残留。测量脚本也修复了 PID 复用导致的 Explorer 误计。最终报告 1793766790293 / 1793766821929：UI 进程组 Private Bytes 峰值约 167.63 MiB；31.1 秒仅核心暂停模式主进程约 4.50–5.74 MiB，没有 WebView2 子进程。都是短期实测，不是固定内存承诺；IO Transfer 含 IPC，不冒充物理磁盘写入。

依赖：WebView2 SDK 1.0.4314.35；JSON 3.12.0；SQLite 已升级至官方当前固定版 3.54.1，ZIP 的 SHA3-256 与官方值一致，Loader Authenticode 为 Microsoft Valid。未修改系统代理、网络设置、驱动或自启动；没有上传监测数据。

已知边界：IPv4/IPv6 分项不能从接口总字节推断；需要权限/额外设备的测试明确留待验收。不得更改代理、防火墙、驱动或自动启用自启动。

外部阻塞：Computer Use 本机管道不可连接（重试和重置后仍失败），因此鼠标式 UI 自动点击尚未执行；不阻止应用内部真实页面导航、截图、消息通信、生命周期与进程测量。

候选发布位置：build/release/PulseTrace-0.2.0-rc1-win-x64/PulseTrace.exe 与同级 ZIP。启动默认暂停，数据留在 exe/data；完整说明见 README。

下一项具体开发任务：在用户提供已授权 ETW 权限和可控独立 IPv4/IPv6 流量真值环境后，开发并验证可选的精确分族后端；同时进行外部 HID、Clash TUN、长时及其他 Windows 验收。当前不安装驱动、不提升权限。恢复开发先读取本文件与实际代码，不把候选版称为最终验收完成。
