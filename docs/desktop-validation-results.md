## 曾失败并修复

- WebView2 SDK 的 GUID 与 MinGW 模板仿真不匹配：改用 Clang 原生 UUID 属性与官方 COM 接口定义，实际编译链接通过。
- Winsock/IP Helper 头文件顺序导致 GetIfTable2 类型缺失：纠正顺序，并固定格式化器不重排 includes。
- 两个资产复制目标并行写同目录造成复制失败：建立构建依赖，按顺序复制。
- 最初完全退出时主进程先于两名 WebView2 子进程结束：改为异步停止核心，再在 UI 消息泵等待 BrowserProcessExited；复测无已观察残留子进程。
- 浏览器崩溃事件顺序可能导致等待已经发生的退出事件：保存 browser_exited 状态并核对事件所属 environment，异常恢复测试通过。
- 退出提交失败时临时重试容器可能随工作线程结束而丢失：保留聚合在 CoreService，并验证排除写锁后重试成功。
- 配置整数先缩窄后校验可能使超大值溢出并通过：改为 JSON 原始整数边界校验，启动加载和在线更新共用校验；实际拒绝 `4294967326`，无效主题也被拒绝。
- 自启动命令参数的尾部反斜杠需要双写：加入 Windows 参数编码，使用 CommandLineToArgvW 验证空值、盘符根目录、带空格尾部斜杠、引号路径。测试不写注册表。
- 最后一次测量将早于主进程启动的 Explorer 误列为后代（PID 复用）：修复进程树创建时间约束；保留 `resource-test-1793766468526.json` 作为失败证据，该报告不能用于计算资源峰值。

失败报告保留为诊断证据，不以删除测试或隐藏结果冒充全程通过。

## 短期资源实测

最终候选二进制复测，不作为任意设备上的固定内存承诺：

| 模式 | 实测 |
| --- | --- |
| 仅 C++ 核心，约 31.1 秒、默认暂停采集 | Private Bytes 约 4.50–5.74 MiB；累计 CPU 0.078125 秒（约 0.25% 单核）；最高 9 线程、245 句柄；没有 WebView2 子进程 |
| UI 打开/隐藏/释放/重开，两个循环 | 主进程 Private Bytes 约 11.27–13.50 MiB；包含本实例 WebView2 子进程的采样峰值约 167.63 MiB；退出后已观察子进程残留 0 |

最终报告为 `resource-test-1793766790293.json`（UI）、`resource-test-1793766821929.json`（Core），主程序均退出码 0、已观察子进程残留 0；报告内保存测量二进制 SHA-256。之前的有效阶段报告 `resource-test-1793764101000.json`、`resource-test-1793764751114.json` 同样保留。500 ms 采样可能漏过短暂进程；Working Set 合计包含共享页；Process IO Transfer 包含 IPC，不等于真实磁盘写入。仅核心模式当前是暂停采集的空闲基线，不能用于宣称高频输入 CPU 达标。

## 尚未执行 / 不支持

- 精确物理出口 IPv4/IPv6 分项字节后端：当前未实现、明确显示未支持。GetIfTable2 的接口总量不作估算拆分；当前非管理员环境不擅自提升权限、安装驱动或改动代理。
- 真实高频 HID 点击、键鼠同时高频事件丢失率、滚轮硬件真值，以及端到端输入延迟；缺独立发生器/外部测量设备。
- 24/72 小时长期运行、吞吐量 A/B、Clash TUN 开关与路由变化对照；没有修改用户的网络或 Clash 配置来伪造测试。
- Windows 10、其他 Windows 11 构建、跨显示器 DPI、其他键盘布局/特殊媒体键、真正锁屏解锁与 Explorer 重启验收。
- 自启动的真实登录流程：代码只由设置页显式操作触发，开发期间没有启用用户 Run 项。
- Computer Use 助手本地 pipe 不可连接，按流程重试及重置仍失败；因此没有声称已完成人工式 UI 点击自动化。内部 WebView2 导航/通信/截图/资源测试仍然实际执行。

已生成并实际运行候选包；最终验收尚未全部完成。普通权限应用功能可试用，但精确分族后端、外部 HID/延迟/长期运行及其他系统验收仍未完成，不宣称完整产品验收通过。
