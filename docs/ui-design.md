# 蓝色主题与科学热力图

> 本文保留上一轮蓝色主题设计。当前默认已改为 ANSI 104 + Arctic（OKLab 连续插值、平方根归一化），网络接入真实 ETW NDIS 观测；以 [最新设计与验收记录](ansi-arctic-network-validation.md) 为准。

当前正式入口是 `web/desktop/index.html`，加载 `colormaps.js`、`visualization.js`、`product.js`。根目录旧 `web/index.html` 不参与桌面运行；未引用的桌面验证 `app.js` 已清理。NativeMessageBridge 和本地虚拟来源继续使用，桌面程序不启动 HTTP 服务；旧 HTTP 工具改为显式选项 `PULSETRACE_BUILD_HTTP_REPORT=ON`。

## 主题与布局

五色板集中在 `style.css` 的 CSS Variables：深海蓝 #0a2639、主蓝 #196090、科技蓝 #3498db、浅冰蓝 #8bc4ea、雾蓝白 #d4e9f7。其余色彩仅为中性色、蓝色派生与状态色。浅色使用雾蓝背景/白卡片/深蓝文字，深色使用深海蓝背景/深蓝卡片/浅色文字。成功绿只在状态语义中使用。热力图的科学色图是独立的数据编码。

正文、次级文字、导航选中、按钮、错误按钮等主题配对由自动测试计算 WCAG 相对亮度与对比度；普通文字目标 4.5:1，曲线与输入边界目标 3:1。浅色下载曲线采用更深的蓝色以保证对白色卡片的对比，不能直接用 #8bc4ea 作白底细线。

主内容最大宽度 1400 CSS px，侧栏 216 px；窄于 1000 px 折叠为 72 px 图标导航，保留 title 和 aria-label。统计卡片由容器查询在 4/3/2/1 列间切换，高度来自内容与合理最小值。Dashboard 的输入/网络每组最多三列，趋势两列，网络趋势独占一行。表格、键盘布局允许组件内部滚动，页面整体不得横向溢出。图表固定 190 CSS px 高度，ResizeObserver 按实际容器与 DPR 调整画布；移除页面时注销观察器。

## 科学热力图

默认 Viridis，可切换 Inferno、Magma、Cividis。四套均来自官方 Matplotlib v3.10.0 `_cm_listed.py`，每套完整 256 项 RGB 浮点查找表，没有用几个锚点假冒标准色图。

- 官方数据：https://github.com/matplotlib/matplotlib/blob/v3.10.0/lib/matplotlib/_cm_listed.py
- 原文件 SHA-256：`ddad3698f5129ceb1792a445371286c08bc9080298e657b3054aea19c9659ef9`
- 官方说明：https://matplotlib.org/stable/users/explain/colors/colormaps.html
- 许可：`web/desktop/assets/Matplotlib-LICENSE.txt`，随发布资源保留。
- 重建：下载上述固定源到 `build/ui-sources/_cm_listed.py`，许可到同目录 `Matplotlib-LICENSE.txt`，运行 `node tools/extract-colormaps.cjs`；脚本核对源文件哈希。

输入是所选范围内真实按下聚合次数。线性归一化 `t=count/max`，LUT 索引为 `min(255, floor(t*256))`，匹配 ListedColormap 取样语义；最高值 0 时不除零。每次查询使用独立 `[0,max]` 标尺，页面显式提醒不同时间范围颜色不可直接比较。色标展示全部 256 颜色及最低/最高次数与单位。

无覆盖记录的范围用虚线中性键、`—`；有覆盖但未发生该键按下用 LUT 起点色与 `0`；正数映射连续色表并显示实际计数。零次不代表所有缺测时段均采集过；状态只依据范围是否有监测覆盖或按下记录。未知扫描码仍保留排名。每个有色键自动选择黑/白文字中对比度更高的一种，小字继承相同颜色，全部四表 1024 个取样均测到文字 ≥4.5:1。

## 趋势与空状态

网络图展示所选接口真实上传/下载聚合，实线上传、虚线下载，提供图例、字节单位和时间轴。IPv4/IPv6 精确分项继续显示“暂不支持”，没有模拟分族曲线。暂停时即时速率显示“已暂停”，历史记录仍可查询。没有记录显示空状态，不造零曲线。

长范围按时间合并相邻桶，每条曲线最多 240 点，保持总量，合并时显示说明；未观测区间不补零，不跨过缺失合并桶连线。单点用圆点，窄画布只显示一个完整时间端点，避免轴标签重叠。

## 原生外观

自有脉冲图标由矢量图与可重现脚本生成；ICO 包含 16/24/32/48/64/128/256 PNG 帧。RC 嵌入资源 101，窗口大/小图标和托盘读取同一资源，安装快捷方式指定 EXE 图标。没有单独的安装/卸载 EXE，脚本安装不会声称具有不存在的卸载程序图标。原生绘制只显示简洁准备提示或失败诊断/托盘重试指引，不显示加载成功调试日志。

本轮没有修改监测核心、数据库结构、Raw Input、WebView2 初始化/释放算法；Win32 修改限于图标、最小尺寸、占位文案与仅自检使用的 DPI 尺寸参数。
