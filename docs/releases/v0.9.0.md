# PulseTrace 0.9.0

Windows 10/11 x64 · 发布准备 / Release preparation · 2026-11-26

## 更新 / Changes

- **主题与配色**（`255a096`） Deep Ocean 和 Pearl Mist 统一系列色。键盘、IPv4 和上行使用海蓝，鼠标、IPv6 和下行使用紫罗兰。监测中使用低调的暂停按钮，暂停时突出恢复操作。浅色次级文字对比度提高，主题可跟随系统。
- **键盘与时间范围**（`d099660`、`55e7245`） Arctic 热力图适配浅色，支持线性／对数色阶、整数图例和 ANSI 104／TKL（87 键）视图。近 1 小时、近 24 小时、今日、本周、近 7 天、本月和全部七个快捷项取代重复的预设下拉框。小时和天可按本地时间或 UTC 分桶。
- **网络与校园网**（`a138c76`） 网络页把接口、IPv4 和 IPv6 汇总为三张双向卡，为首屏趋势图留出空间。低余额和低免费流量可通过 Windows 本地通知提醒，默认关闭。提醒按门户、类型和账期去重，无法识别账期时使用 24 小时冷却。
- **总结卡片与峰值**（`23b6757`） 总览可将所选时段导出为深／浅主题 PNG，自选统计内容，音乐默认不勾选。峰值 KPM／APM 基于已有分钟聚合。
- **Windows 自启**（`35987a7`） 识别任务管理器禁用的 Run 项，校准因移动便携版而失效的旧路径，支持以最高可用权限运行当前账户的登录计划任务。早期启动错误写入 `%TEMP%\PulseTrace-startup-error.log`。
- **Phase A 趣味洞察**（`da8553a`） 新增 SVG 十指负载、左右手占比和打字纠错指数。空格按双拇指共用单列。鼠标滚轮按每个标准格 3 mm 估算里程。键鼠额定寿命可配置，预计剩余年限使用至少 7 天的观测跨度外推。总览新增折叠成就，单曲成就按需查询。
- **Phase B 节律和环比**（`61b4b8f`） 历史页新增 7×24 昼夜节律矩阵，支持悬停和方向键查看平均值、总量与观测小时数。365／366 天年度活动墙可切换按键、点击、有效活跃时长、接口流量和已启用的音乐时长。总览在有有效上期基线时显示环比。
- **Phase C BGM Buff**（`6f43088`） 启用音乐且有播放记录时可按需查看高能战歌榜、软件专属配乐和单日按键趋势曲目标记。榜单要求播放与键盘观测估算重合至少 5 分钟。前台应用关联也从已有分钟时长估算。
- **Phase D 脉冲模式**（`b386c96`） 顶栏可进入深色双轨示波画布，支持当前显示器全屏、Esc 或双击退出。海蓝轨反映键鼠变化，紫罗兰轨反映网速变化，角落显示本地时钟、今日键鼠累计和启用时的当前 SMTC 曲目。退出、隐藏或最小化时停帧并释放 Canvas 缓冲。

- **Themes and colors** (`255a096`). Deep Ocean and Pearl Mist use blue for keyboard, IPv4 and upload, and violet for mouse, IPv6 and download. Pause is subdued while monitoring and Resume is emphasized when paused. Pearl Mist has stronger secondary text contrast, and the theme can follow Windows.
- **Keyboard and time ranges** (`d099660`, `55e7245`). Arctic adapts to the light theme. The heatmap supports linear and logarithmic scales, integer legends, and ANSI 104 or TKL (87 keys). Last Hour, Last 24 Hours, Today, This Week, Last 7 Days, This Month and All Data replace the duplicate preset menu. Hour and day buckets support local time or UTC.
- **Network and campus portal** (`a138c76`). Three bidirectional cards cover interface totals, IPv4 and IPv6, leaving room for traffic trends near the top. Optional Windows alerts for low balance or low free data are disabled by default. They deduplicate by portal, alert type and billing period, with a 24-hour cooldown when the period is unknown.
- **Summary cards and peaks** (`23b6757`). Export the selected period as a light or dark PNG with selectable contents. Music is unchecked by default. Peak KPM and APM use existing minute aggregates.
- **Windows startup** (`35987a7`). Detects Run entries disabled in Task Manager, repairs stale paths after a portable installation is moved, and offers a per-user logon task with the highest available privileges. Early startup errors go to `%TEMP%\PulseTrace-startup-error.log`.
- **Phase A, input insights** (`da8553a`). Adds an SVG ten-finger load chart, left/right-hand share and a typing correction ratio. Space is counted separately as shared by both thumbs. Wheel distance assumes 3 mm per standard detent. Rated keyboard and mouse lifetimes are configurable, with remaining-life estimates based on at least seven days of observations. The collapsible Dashboard achievements query the repeat-track achievement on demand.
- **Phase B, activity rhythms and comparisons** (`61b4b8f`). History adds a 7×24 rhythm matrix with hover and arrow-key access to averages, totals and observed hours. The 365/366-day activity grid supports keystrokes, clicks, active time, interface traffic and music duration when enabled. Dashboard period comparisons appear when a valid prior baseline is available.
- **Phase C, BGM Buff** (`6f43088`). With music tracking enabled and playback data available, expand the panel for typing-rate rankings, app associations and optional track markers on single-day keystroke trends. The ranking requires at least five minutes of estimated playback and keyboard coverage overlap. App associations also use estimates from existing minute durations.
- **Phase D, Zen Pulse** (`b386c96`). The toolbar opens a dark dual-trace canvas with fullscreen on the current monitor, Esc or double-click to exit, blue input and violet network traces, a local clock, today's input totals and the current SMTC track when enabled. Exiting, hiding or minimizing stops frames and releases the canvas backing buffer.

## 安装与升级 / Install and upgrade

- 升级前从托盘完全退出旧程序，保留 `data`。便携版需完整解压，运行需要 Microsoft Edge WebView2 Evergreen Runtime。
- 从 v0.8.0 升级沿用 **SQLite schema 9**，无需数据库结构迁移。现有采集链路保持原样。新洞察使用已有聚合数据。
- v0.9.0 安装包与便携包待正式发布。音乐统计需在设置中启用，并开启主监测开关。SMTC 需要 Windows 10 1809 或更新系统。

Quit the old tray process and keep the `data` directory. Extract the complete portable ZIP. Microsoft Edge WebView2 Evergreen Runtime is required. Upgrading from v0.8.0 retains **SQLite schema 9** and requires no schema migration. The capture pipeline remains unchanged. The new insights use existing aggregates. v0.9.0 installer and portable packages are pending release. Music tracking requires opting in and enabling monitoring. SMTC requires Windows 10 1809 or later.

## 验证与限制 / Validation and limits

- Windows x64 Release 构建、完整 CTest **38/38** 和 README 校验已通过。原生 WebView2 自检覆盖双语、深浅主题及实际最小化后的停帧与恢复。实际 Windows DPI 为 125%，Canvas 的 150% 像素比例通过 WebView2 缩放模拟验证。
- 校园网阈值与去重、PNG 生成与落盘、计划任务定义、BGM 时间重合及脉冲波形均有合成数据或隔离测试。滚轮里程、硬件寿命和 BGM 重合为估算。年度视图取决于各模块保留的数据。
- 尚未真机复测真实校园网触发 Windows 通知、PNG 交互式另存为、管理员计划任务注册后重新登录、QQ 音乐／网易云真实长时间播放联测、混合 DPI 双屏切换及长期后台 CPU／内存占用。正式安装包的验证结果将在发版时记录。

- The Windows x64 Release build, full CTest suite (**38/38**) and README checks passed. Native WebView2 self-tests covered both languages and themes, as well as stopping and resuming frames across actual minimization. Windows was at 125% DPI. The 150% canvas pixel ratio was exercised through simulated WebView2 scaling.
- Synthetic or isolated tests covered campus thresholds and deduplication, PNG generation and file writing, task definitions, BGM overlap and pulse traces. Wheel distance, hardware lifetime and BGM overlap are estimates. The annual grid depends on each module's retained data.
- Pending real-world checks include Windows alerts triggered by a live campus portal, the interactive PNG Save As dialog, re-logon with an administrator task, sustained QQ Music and NetEase playback, mixed-DPI dual-monitor switching, and long-duration background CPU and memory use. Package validation results will be recorded at release.
