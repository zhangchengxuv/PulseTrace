# PulseTrace 0.3.0-rc1

- 深蓝日期时间选择器：独立草稿、确认/取消、键盘导航，实时刷新不销毁弹窗。
- 独立 Win32 任务栏网速 helper，使用现有物理接口速率；空间无法验证时安全回退。
- GitHub / Gitee 双源检查与下载，语义化版本、同版 SHA-256 一致性校验、取消及诊断。
- SQLite Online Backup、顺序事务迁移、未来 schema 拒绝、配置兼容与备份入口。
- 每用户 EXE 安装器、独立数据目录、主动便携导入、升级前备份、卸载保留数据。

候选版本限制：没有配置可信的 PulseTrace 发布签名，所以下载后采用手动安装，不自动执行 EXE；物理 IPv4/IPv6 仍为未完成独立对照验收的观测。任务栏已验证当前 Windows 11 /125%，其他系统/多屏/DPI/自动隐藏需人工验收。旧程序升级请先从托盘完全退出。历史与月度数据不作为安装资源覆盖。
