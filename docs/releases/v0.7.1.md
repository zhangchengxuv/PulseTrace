# PulseTrace 0.7.1

Windows 10/11 x64 / 2026-11-07

## 更新 / Changes

- 修复 IPv4/IPv6 实时监控自动选错网卡：优先选择有默认路由的物理接口，比较路由与接口成本，同等成本保持当前接口；显式选卡仍按用户设置执行，TUN/VPN 不与物理接口相加。
- ETW 采集启动失败后每 30 秒重试；消费者意外退出时安全收尾并尝试恢复，失效速率显示未知，暂停/恢复可重新尝试。
- 移除任务栏网速组件、悬浮网速、相关设置、IPC 和打包依赖。网速继续在 Dashboard/Network 显示，系统托盘、关闭到托盘和后台监测保留。设置现为七类导航。
- 安装升级清理旧网速组件及旧前端脚本；保留原数据库、统计历史、校园网规则、云备份与旧配置兼容性。

Fixes automatic selection of a connected adapter without a default route when traffic uses another physical adapter. Automatic selection now considers route and interface costs, preserves equal-cost selections and respects explicit choices. Failed ETW sessions retry with a 30-second limit; stopped consumers are cleaned up, and invalid rates remain unknown.

Removes the taskbar/floating speed helper, its settings, IPC and package dependencies. Dashboard/Network rates, system tray and background monitoring remain available. Settings has seven categories. Upgrades remove the retired helper and script while preserving statistics and configuration.

## 安装与升级 / Install and upgrade

- 安装版：`PulseTrace-Setup-v0.7.1-x64.exe`；便携版：`PulseTrace-v0.7.1-x64.zip`。GitHub/Gitee 使用相同的五个附件及 SHA-256 校验文件。
- 从托盘完全退出旧程序，安装到原目录并保留 `data`，无需先卸载。便携版完整解压至新目录后迁移原 `data`，不要只替换 EXE。需要 Microsoft Edge WebView2 Evergreen Runtime。
- 若曾手动指定无流量的网卡，请在设置 → 监测中改选实际接口或自动选择。自动模式只观察一个物理接口，不汇总多网卡或 TUN。

Quit the old tray process before upgrading and keep the existing data. Extract the complete portable archive; migrate data only after the old process exits. WebView2 Evergreen Runtime is required. If an inactive adapter was explicitly selected, select the active interface or automatic mode in Monitoring settings.

## 验证范围 / Validation scope

- 开发构建已完成 Release/Debug 各 32/32 CTest、最终前端各 6/6 复核、真实 IPv4/IPv6 双向被动观测、800×600 DIP 原生七分类设置、便携包完整性及旧布局升级保留数据测试。发布准备流程再次执行双配置测试、中英安装向导、隔离安装/运行中升级/卸载/重装及便携包验证；回执绑定本版源码提交与附件哈希。
- 真实观测仍未经独立抓包计量对照；全部网卡/代理组合、ETW 故障自动恢复的实机故障注入和长期资源上限尚未验收。不将观测子集视为完整计费流量。
- 真实坚果云连接/上传/异机恢复及真实校园网长期登录/认证恢复仍需外部验证。未配置发行者代码签名，下载安装保持手动执行。

Tests cover both build configurations, network selection, packet parsing, persistence, UI and isolated upgrade/portable workflows. Passive IPv4/IPv6 observations were received, but independent packet-reference accuracy, all adapter/proxy combinations, live ETW failure injection and long-term resource limits remain unverified. Live Jianguoyun/campus authentication and cross-device restore retain their existing validation limits. Installers have no publisher code signature.
