# PulseTrace 0.6.1

Windows 10/11 x64 正式版 / Stable release

## 修复 / Fixes

- 修复“点击网页选择”在门户未打开或仍在加载时不弹出网页的问题。现在会自动打开已配置的内置门户，恢复隐藏/最小化窗口并置前；页面就绪后再进入点选。
- 复用已登录页面，点选不会重新加载网页；快速选择多个字段时，以最后一个字段为准。等待配置保存完成后再打开，避免读取旧地址。
- 打开、需登录、就绪及失败提示显示在对应按钮下方。关闭门户取消点选，登录表单不拦截点击，点选期间自动刷新不会打断操作。
- 保留 v0.6.0 的校园网后台同步、计费计算、页面切换复用、双主题和中英双语。数据库 schema 不变，保留既有数据和规则。

Fixes the campus “Pick from page” action when the portal is closed, hidden, minimized or still loading. The built-in portal now opens or restores immediately, then prepares the latest requested field after loading without reloading an authenticated page. Per-field progress and errors stay beside the button. Pending settings saves complete first; closing the portal cancels selection, and sign-in forms remain usable.

## 安装与限制 / Installation and limitations

- 安装版运行 `PulseTrace-Setup-v0.6.1-x64.exe`；便携版完整解压 ZIP 后运行 `PulseTrace.exe`。升级前从托盘完全退出程序，保留原 `data` 目录。
- 本轮使用隔离本地模拟门户验证，未访问真实高校账号。学校专用官方接口、真实 OS 锁屏/休眠、长期后台资源及其他 DPI/刷新率仍待外部验收。
- 校园网默认关闭；已启用的 DOM 后台同步需要一个可选的隔离 WebView2。发布包没有发行者代码签名，安装保持手动执行。

Quit the app completely before upgrading and retain existing data. Validation uses isolated local mock portals; real university accounts, institution-specific APIs, real OS transitions and long-running resource use remain unverified. Enabled DOM monitoring retains an optional isolated WebView2. Packages have no publisher code signature; installation remains manual.
