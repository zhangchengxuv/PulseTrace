# PulseTrace 0.7.2

Windows 10/11 x64 / 2026-11-08

## 更新 / Changes

- 修复校园网门户 MB/GB 按十进制解析、与 GiB 额度和单价混算的问题。校园网默认 1024 进位，可切换 1000；界面使用学校 GB/MB，显式 IEC 单位仍保持标准定义，其他网络统计不变。
- 保留门户原始数值、单位、采集进位与来源。SQLite schema 8 增量迁移保留旧历史；可靠旧读数从源单位恢复，无法确定的旧记录待确认，不重复换算。同步失败保留上次有效数据。
- 保留旧元/GB、元/GiB 单价的金额和字节基准，设置显示当前学校元/GB 等价值，实际编辑后采用新口径。资金可用量要求确认单一费率及余额用途，不重复扣除已付费用；免费优先推算要求确认本账期与相同统计范围，每月重新确认。
- Dashboard/Network 共用计算，免费进度以免费总额度为分母；真实余额、原始已用和估算购买能力分别标识。必要数据或规则缺失时显示“无法计算”。支持中英双语、深浅主题，保留监测、托盘与加密 WebDAV。

Fixes mixed decimal portal parsing and binary allowance/price calculations. Campus units default to base 1024 with a base-1000 option; explicit IEC units retain their standard definitions. Raw readings and capture metadata survive schema-8 migration without rewriting historical observations. Legacy price amounts and byte bases are preserved; derived billing requires confirmed scope and tariff rules. Dashboard and Network share consistent calculations and a free-allowance progress denominator. Failed synchronization retains the last valid data.

## 安装与升级 / Install and upgrade

- 安装版：`PulseTrace-Setup-v0.7.2-x64.exe`；便携版：`PulseTrace-v0.7.2-x64.zip`。GitHub/Gitee 使用相同的五个附件及 SHA-256 校验文件。
- 从托盘完全退出旧程序，安装到原目录并保留 `data`，无需先卸载。便携版完整解压至新目录后迁移原 `data`，不要只替换 EXE。需要 Microsoft Edge WebView2 Evergreen Runtime。
- 升级前保留备份；schema 8 不应直接交给旧版本打开。校园网设置中核对换算方式、免费额度及单价；只有明确同账期、同范围及免费优先规则后才确认推算。旧记录缺失源单位时等待重新同步或人工确认。

Quit the old tray process before upgrading and keep existing data. Extract the complete portable archive; migrate data only after the old process exits. WebView2 Evergreen Runtime is required. Keep a backup before migration; older versions must not open a schema-8 database. Confirm campus conversion, allowance, price and accounting scope before enabling derived billing.

## 验证范围 / Validation scope

- 开发阶段 Release/Debug 各 32/32 CTest 通过，最终相关复验各 10/10；覆盖单位切换、IEC、旧价、缺失/零值、跨期、原始读数刷新、数据库迁移与重启及云归档计量配置。原生 WebView2 已验证 Dashboard/Network/Settings、两种主题及合成无数据/部分/完整状态。
- 发布准备流程重新执行双配置构建与完整测试、中英安装向导、隔离安装/升级/卸载/重装、旧布局迁移及便携包验证，回执绑定本版源码提交和附件哈希。
- 门户同源代码存在 1024 换算，但不能证明“流量(V4)”的统计范围、账期、上下行、免费扣除状态和最终计费口径，需依据校方说明确认。不将推算当作官方计费结果。
- 真实账期重置、长期锁屏/休眠/断网恢复、独立抓包计量、全部网卡/代理组合及真实坚果云连接/上传/异机恢复仍需外部验证。安装包未配置发行者代码签名。

Tests cover both configurations, conversion and billing edge cases, migration, restart, encrypted backup metadata and native UI states. Release preparation validates installers and portable artifacts against the clean source commit. Portal scripts show base-1024 arithmetic but do not establish accounting scope or billing semantics. Live billing-cycle resets, long-term recovery, independent traffic accuracy and live Jianguoyun interoperability remain unverified. Installers have no publisher code signature.
