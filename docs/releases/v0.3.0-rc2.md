# PulseTrace 0.3.0-rc2

- 修复 Windows 11 任务栏子窗口有 HWND 但实际不可见：layered child 合成、真实文字像素核验、遮挡回退和正确 Segoe UI Variable 字体。
- 简体中文/英语集中资源，覆盖六页、日历、更新、托盘和网速菜单；设置切换不重启采集。
- 安装/卸载中英语言；安装目录只选一次，数据固定在 data 子目录。
- 默认 D:\Program Files\PulseTrace，提前检查权限；只为实际用户的数据目录授予写权限，程序文件只读执行。
- 旧版独立数据目录一致性备份迁移、非空目标保护、普通卸载保留数据和重装恢复。

候选版：默认 D 目录提升安装、其他 Windows/语言/DPI/多屏、Explorer 重启及长期运行仍需人工验收。安装包未建立可信签名身份，不启用自动 EXE 执行；IPv4/IPv6 继续标注真实观测的限制。
