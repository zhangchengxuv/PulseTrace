# PulseTrace 0.3.0-rc3

Windows 10/11 x64 候选版 / Release candidate

## 更新 / Changes

- 新增应用使用统计：前台停留与输入空闲阈值内的有效活跃时间分列，提供排行、日/小时趋势、排除列表与 CSV。仅保存分钟聚合，不记录窗口标题、文档或 URL。
- 新增 Pearl Mist 浅色主题，保留 Deep Ocean 与跟随系统；主题即时保存，原生标题栏同步。
- Network 增加应用/连接域名流量排行。Windows ETW 与可选 Mihomo 数据源分开显示，域名历史显式启用；采样缺口、未知归属和权限不足明确标注，不与物理接口流量相加。
- 任务栏网速采用逐像素透明背景，兼容已有任务栏材质；可选淡色回退。修复托盘初次注册失败后的恢复及重复注册问题。
- 精简静态文案与文字选择，保留日期、表单、表格及可复制区域。复用数字格式化对象并完善 DPI/可见性重绘；不宣称整体 CPU 或内存已下降。

English: foreground/idle-aware App Usage with minute aggregates, rankings and CSV; Pearl Mist theme; independent application/domain traffic rankings; transparent taskbar speed display; reliable tray registration recovery; concise UI and bounded formatter/DPI rendering work. No input content, window titles, URLs or packet payloads are recorded.

## 数据与升级 / Data and upgrade

SQLite Schema v5：结构升级前使用一致性 Online Backup，事务迁移保留旧历史、月档和配置。普通升级与卸载保留 `<安装目录>\data`。便携版请保留原 data 并先完全退出旧程序；首次启动仍默认暂停（已有主动启用的启动采集偏好保留）。旧版程序不能直接写入 v5 数据库，降级需恢复兼容备份。

Schema v5 uses consistent pre-migration backups and transactional upgrades. Existing history, monthly archives and preferences are retained. Normal uninstall keeps data. Older binaries must use a compatible backup rather than write the newer database.

## 验证与限制 / Validation and limitations

发布前执行 Release/Debug 构建、18 项 CTest，以及安装器启动、中英安装/升级/卸载保留、旧版迁移、便携包完整性和真实 WebView2 运行检查；具体结果绑定发布提交保存在 `validation-v0.3.0-rc3.json`。

受控前台激活曾被 Windows 拒绝；应用使用时长的锁屏/睡眠/注销、多进程压力、其他系统/DPI/多屏及长期运行仍待人工验收。输入空闲不等于绝对实际使用时间。Windows 进程 ETW 可能权限不足；Mihomo 为采样下界，物理 IPv4/IPv6 仍未完成独立抓包/计费对照。

Controlled foreground activation, lock/suspend/session transitions, additional Windows/DPI combinations and long-running hardware tests remain pending. Idle detection is approximate. ETW may require additional permissions; sampled connections and physical IP observations are not billing totals.

安装包尚无可信发布签名，可能触发 SmartScreen；在线更新提供校验后的手动安装回退，不静默执行未验证 EXE。需系统 Microsoft Evergreen WebView2 Runtime。附件为安装 EXE、便携 ZIP 及各自 SHA-256，不含用户数据库、凭据、日志或浏览器配置。

Unsigned installer; no unattended execution of downloaded EXEs. Microsoft Evergreen WebView2 Runtime is required. Assets include the installer, portable ZIP and SHA-256 sidecars, without user data.
