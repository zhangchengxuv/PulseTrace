# PulseTrace 0.3.0-rc4

Windows 10/11 x64 候选版 / Release candidate

## 更新 / Changes

- 新安装默认目录改为 D:\Program Files (x86)\PulseTrace，数据固定为实际安装目录的 data 子目录。D 盘不存在时仍回退到当前用户的 Programs 目录；权限不足时提示选择其他位置或明确提升安装器。升级沿用原安装位置，不迁移或覆盖已有数据。程序仍为 x64。
- 更新鼠标按键可视化、全部已保存历史的默认查询范围、自然月流量日历、每次打开界面的异步更新提示及极简启动。优化 Network 信息层次、折叠分页、Settings 分组和任务栏网速字体/单位/位置设置。
- 修复范围与页面切换的异步响应竞态；修复 IPv4/IPv6 不同采集来源或字节口径的误合并，无法比较时明确提示而不生成分项总量。
- 降低启动时月度归档恢复的重复打开与摘要写入开销，保留逐批事务、故障后重试和原始记录。

New installations default to D:\Program Files (x86)\PulseTrace; data stays under the actual installation's data folder. Drive-D fallback and permission checks remain. Upgrades retain their existing location and data. Binaries remain x64.

This candidate also includes mouse visualization, all-history defaults, a monthly traffic calendar, asynchronous update notices, concise loading, Network/Settings organization and taskbar typography/unit/position controls. It fixes stale refresh responses and incompatible protocol-traffic aggregation, and reduces repeated archive recovery work without changing collection algorithms.

## 数据与升级 / Data and upgrade

数据库 Schema 仍为 v5；升级保留键鼠/应用使用/网络历史、月度归档和设置。旧月度 JSON 摘要缓存从保留的 SQLite 重建，缓存格式为 2；不同来源/口径的分项合计为未知，不删除原始记录。安装和普通卸载保留 data。升级前完全退出便携版；首次运行默认暂停，已有主动开启的启动采集设置保留。

Schema remains v5. History, monthly archives and preferences are preserved. Old derived monthly summaries are rebuilt from SQLite as cache format 2. Incompatible IP observations remain separate and their combined totals are unavailable. Normal uninstall preserves data. Fully exit a portable instance before upgrading.

## 验证与限制 / Validation and limitations

本版验证结果绑定发布提交及四个附件的 SHA-256，见本地 validation-v0.3.0-rc4.json；测试使用隔离数据。保留已发布 rc3 附件，不覆盖旧版本。

Release validation is bound to its source commit and four asset hashes. Tests use isolated data; existing rc3 assets are retained.

安装包尚未签名，可能触发 SmartScreen；更新下载校验后提供手动安装，不静默执行未知 EXE。需要 Microsoft Evergreen WebView2 Runtime。部分受保护目录需要用户明确提升安装器或选择可写位置，程序普通运行无需管理员权限。

Windows 进程 ETW 可能权限不足，Mihomo 为连接采样下界；物理 IPv4/IPv6 尚待独立抓包对照，不能当作校园网计费。Windows 10、真实多屏/其他 DPI/高刷新率、TranslucentTB 各模式、锁屏/睡眠及长时间硬件测试仍待人工验收。

The installer is unsigned and may trigger SmartScreen. Verified downloads use manual installation. Microsoft Evergreen WebView2 Runtime is required. Protected destinations require an explicitly elevated installer or a different location; normal app operation does not require administrator rights. ETW permissions, sampled connections and physical IP observations have known coverage limits and are not billing totals. Additional Windows/display/session/hardware validation remains pending.
