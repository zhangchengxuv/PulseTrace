# PulseTrace 0.6.0

Windows 10/11 x64 正式版 / Stable release

## 更新 / Changes

- 校园网设置简化为基础设置、校园网概览、计费设置与默认折叠的高级设置。自动识别结果预填后由用户确认，支持网页点选纠正；普通用户无需编写公式或选择器。
- 修复免费额度、普通套餐剩余及付费已用混算；支持 GB/GiB 单价。仅在用户确认免费优先分配、余额可用于流量时采用相应计算。缺失字段、未知账期和零单价显示无法计算，已扣费用不会再次从余额扣减。
- 修复千位分隔、小写单位、隐藏字段及登录页识别，支持全部 11 个映射字段同步，规则确认后立即生效。
- 校园网登录并确认规则后，关闭门户或主窗口到托盘仍在后台同步，正常启动自动恢复隐藏门户。禁用校园网或退出应用停止同步；查询失败和登录失效保留最后有效快照。
- 增强锁屏/休眠恢复、网络失败重试及浏览器回调生命周期防护。应用配置、SQLite 与日志不保存密码、Cookie 或 Token；浏览器会话由独立 WebView2 管理，并禁用密码自动保存和通用表单自动填充。
- 页面切换复用已访问页面及图表，保留草稿、筛选和滚动位置；无需等待数据查询完成才切页。公共导航与工具栏保持稳定，内容区使用 150 ms 淡入并尊重减少动态效果。
- 保留 Deep Ocean、Pearl Mist、中英双语和既有数据库兼容能力。

Campus monitoring now offers a simpler setup and explicit recognition confirmation, conservative free/paid data calculations, GB/GiB pricing and hidden background synchronization. Failed queries and expired sign-in preserve the last valid snapshot. Navigation reuses page views and charts, restores state before painting and respects reduced motion. Existing user data and database compatibility are preserved.

## 使用与限制 / Usage and limitations

- 安装版运行 `PulseTrace-Setup-v0.6.0-x64.exe`；便携版完整解压 ZIP 后运行 `PulseTrace.exe`。升级前完全退出程序；不要删除既有 `data`。
- 校园网默认关闭。启用并登录确认后，DOM 同步需要保留一个可选的隔离 WebView2；关闭门户窗口会隐藏它，停用开关或退出应用才释放。后台同步的长期资源开销尚未验收。
- 未接入学校专用官方查询接口，通用 DOM 识别不能覆盖全部门户、Shadow DOM、Canvas 或跨域 iframe。未使用真实高校账号验证登录、验证码/MFA、计费一致性及长期同步。
- 锁屏/休眠恢复使用测试自身窗口的模拟消息验证，不能替代真实系统转换；其他 DPI、刷新率、Windows 环境和长期运行仍待外部验收。
- 发布包未提供发行者代码签名；更新下载后保留手动安装流程，不自动执行安装程序。

Campus monitoring is off by default. Confirmed DOM monitoring retains an optional isolated WebView2 while enabled, including in the tray. No real university account, institution-specific API, long-running background workload or real OS sleep/lock transition was validated. Packages have no publisher code signature; installation remains manual.
