# PulseTrace 0.7.3

Windows 10/11 x64 / 2026-11-09

## 更新 / Changes

- 校园网设置简化为“网页数据、手动配置、自动计算”三组。默认仅建议余额和已用流量；“流量(V4)”保留 IPv4 范围，其他真实字段在默认折叠的高级识别中扩展，不再逐项映射不存在的元素。
- 额度、元/GB 单价、1024/1000 换算、按月/按年账期与起始日期自动保存；月末、闰日正确对齐。免费已用可选手动填写，跨期失效。免费优先计算需要确认当前账期、协议及上下行口径；费率及余额用途不明确时显示“无法计算”。
- 免费剩余、估算付费购买量、总可用、免费进度及估算费用只读显示，无需编写公式。保留 Dashboard/Network 概览、中英双语与深浅主题；重复数据不重建设置结果区域。
- 兼容旧字段映射、手动值、安全公式及旧单价经济基准，SQLite schema 8 与历史快照不变；同步失败保留上次有效数据。不改动其他监测及加密 WebDAV 功能。

Campus settings now separate webpage readings, manual billing parameters and read-only calculations. Only balance and used data are suggested by default; IPv4 labels retain their scope, and extra real fields remain available through collapsed advanced controls. Monthly/yearly periods use an anchored start date with month-end/leap-day handling. Manual free usage expires next period; derived billing requires explicit scope and tariff confirmation. Existing rules, legacy price bases and schema-8 history remain compatible.

## 安装与升级 / Install and upgrade

- 安装版：`PulseTrace-Setup-v0.7.3-x64.exe`；便携版：`PulseTrace-v0.7.3-x64.zip`。GitHub/Gitee 使用相同五个附件及 SHA-256 校验文件。
- 从托盘完全退出旧程序，安装到原目录并保留 `data`，无需先卸载。便携版完整解压至新目录后迁移原 `data`，不要只替换 EXE。需要 Microsoft Edge WebView2 Evergreen Runtime。
- 升级前保留备份；低于 schema 8 的旧版本不应打开已升级数据库。旧规则自动兼容，无需清空配置；核对账期、起始日期及口径，再确认免费优先和余额用途。

Quit the old tray process before upgrading and retain existing data. Extract the complete portable archive before migrating data. WebView2 Evergreen Runtime is required. Keep a backup; older versions without schema-8 support must not open the upgraded database. Review billing periods, scope and balance use before enabling derived calculations.

## 验证范围 / Validation scope

- 开发阶段 Release/Debug 各 32/32 CTest 通过；覆盖默认两字段、多结构识别、手动点选路由、保存失败、1000/1024、旧价兼容、余额缺失、零单价、按月/按年、月末闰日、跨期失效、SQLite 历史与重启恢复。
- 原生 WebView2 Settings/Dashboard/Network、中英及深浅主题、小窗口布局、无/部分/完整数据与 DOM 保留检查通过。用户授权门户只读实测识别到余额及 IPv4 已用，两项内存规则回放通过，未点击网页控件或修改用户数据。
- 发布准备重新执行双配置完整构建测试、中英安装向导、独立 AppId 安装/升级/卸载/重装、旧布局迁移和便携包校验，验证回执绑定本版干净源码提交及附件哈希。
- “流量(V4)”标签及只读测试不能证明其账期、上下行、免费抵扣或最终资费，仍需校方说明或用户确认。真实跨期、长期断网/锁屏/休眠恢复、独立流量计量及真实坚果云异机恢复仍需外部验收；安装包未配置发行者代码签名。

Both build configurations passed all 32 development tests. Native UI checks cover themes, locales, responsive layouts, data states and stable DOM updates. Authorized live read-only discovery/replay found the two expected fields, but cannot establish their billing semantics. Release preparation validates both configurations, isolated installer lifecycles, legacy layouts and portable checksums against the clean source commit. Long-term recovery, independent traffic accuracy and live cross-device Jianguoyun restore remain externally unverified. Installers have no publisher code signature.
