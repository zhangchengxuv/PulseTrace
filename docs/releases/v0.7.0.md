# PulseTrace 0.7.0

Windows 10/11 x64 / 2026-11-07

## 更新 / Changes

- 新增默认关闭的坚果云 HTTPS WebDAV 云备份：第三方应用密码、DPAPI 凭据保护、强制 AES-256-GCM 加密、SQLite Online Backup 一致性快照、自动备份、上传后下载校验、备份记录与云端列表。恢复先校验，输入 RESTORE 并经原生确认后于下次启动执行，自动保存原数据并支持中断回滚。没有实时双向数据库同步。
- Settings 改为常规、监测、任务栏、校园网、云备份、数据、更新、关于八类导航；保留全部设置，统一布局与保存反馈，高级选项折叠，隐藏类别停止轮询。支持双主题、中英双语及窗口缩放。
- Dashboard/Network 校园网概览使用三项核心指标、分段流量图例、同步状态及真实来源；估算明确标记，缺失数据不伪造，不因校园网更新重建整页。
- 任务栏上传/下载箭头与数字采用紧凑双行排版，测量字体/字号/DPI，固定数字宽度，保留透明背景、原生嵌入及位置/单位设置。
- 网络页移除流量排行及其刷新请求，保留 IPv4/IPv6、趋势、月度热力图、校园网及原历史。键位排名默认收起，显示最高频摘要，展开后分页查看全部键位，并修复即时刷新重置展开状态；ANSI 104 热力图保留。
- 包含校园网全部 11 字段点选协议修复与分列页面识别改进。原配置及数据库 schema 保持兼容，不删除旧数据或规则。

Adds optional encrypted Jianguoyun WebDAV backup, eight settings categories, campus overview cards and compact font/DPI-measured taskbar rates. Network ranking UI and its refresh requests are removed without deleting history. Keyboard rankings collapse by default and retain their state across redraws. Includes all 11-field campus-picker fixes and support for separate label/value columns. Existing data and configuration remain compatible.

Cloud credentials use Windows DPAPI; uploads require AES-256-GCM archives from SQLite Online Backup snapshots. Uploaded bytes are downloaded again for verification. Restore requires validation, typing RESTORE and native confirmation, then runs on the next locked startup with safety copies and a durable rollback journal. This is backup/restore, not live bidirectional synchronization.

## 安装与升级 / Install and upgrade

- 安装版：`PulseTrace-Setup-v0.7.0-x64.exe`。便携版：`PulseTrace-v0.7.0-x64.zip`。两个仓库使用相同附件与 SHA-256 校验文件。
- 从托盘完全退出旧程序，再安装到原目录，保留 `data`；无需先卸载或删除数据库。便携版请完整解压，保留 Web 资源、DLL 和 helper。
- 需要 Microsoft Edge WebView2 Evergreen Runtime。云备份使用坚果云第三方应用密码及单独的至少 12 字符恢复口令；妥善保存恢复口令，丢失后无法解密备份。
- 归档上限 128 MiB/512 文件，自动周期最少一小时。恢复后采集默认暂停；本地现有 SQLite 和临时校验快照本身不加密。

Quit the tray process before upgrading; keep the existing installation directory and data. Extract the complete portable archive. WebView2 Evergreen Runtime is required. Keep the separate recovery passphrase safe. Archives are limited to 128 MiB/512 files, automatic backups to at least one hour apart; capture remains paused after restore. Existing local SQLite and temporary validation snapshots are not encrypted by the cloud archive feature.

## 验证范围 / Validation scope

- 开发验证包括 Release/Debug 构建和各 32 项 CTest、后续相关增量回归、双主题/双语原生 WebView2 布局、任务栏四字体及 100–250% 模拟 DPI 检查。
- 云备份使用真实 DPAPI/加密/SQLite 核心链路和模拟 WebDAV transport，覆盖认证、空间、限流、取消、上传中断、完整性失败、恢复确认、schema 拒绝及回滚。未提供真实坚果云凭据，**未声称官方服务端连接/上传/恢复或异机恢复实测通过**。
- 任务栏实际嵌入因当前可用位置被占用而未完成新版可视验收；TranslucentTB 各模式、其他真实 DPI/刷新率、长时间/大数据量运行及真实校园网登录/认证恢复仍待外部验收。
- 安装包没有发行者代码签名，保持手动下载安装。完整行为与限制见随包 `docs/cloud-backup.md`。

Controlled tests cover Release/Debug, native bilingual/theme layouts, simulated taskbar DPI, encryption, DPAPI, Online Backup and injected WebDAV/restore failures. Live Jianguoyun behavior, cross-device recovery, long runs, large datasets, real campus authentication and additional hardware/TranslucentTB modes remain unverified. The current occupied taskbar layout prevented new visible embedding acceptance. Packages have no publisher code signature; installation remains manual.
