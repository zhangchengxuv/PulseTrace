# PulseTrace 0.8.0

Windows 10/11 x64 / 2026-11-11

## 更新 / Changes

- 新增默认关闭的音乐统计：只读 Windows SMTC，分别启用 QQ 音乐 / 网易云音乐，记录检测播放时长及有效播放次数，连续阈值默认 30 秒，可配置。
- 新增 Music 页面：当前媒体会话、歌曲/歌手 Top 10、每日/周/月趋势、播放器筛选、可选跨播放器合并、全部历史/自定义范围与 CSV 导出；支持中英双语及 Deep Ocean / Pearl Mist。
- 暂停、切歌、拖动进度、退出、锁屏及休眠按保守计时处理；临时暂停保留会话身份，防止同一播放重复计次。只保存分钟聚合，不记录逐秒轨迹、账号、Cookie、歌词或音频，不控制或注入播放器。
- SQLite schema 8→9 新增音乐聚合表及索引，保留原有统计与配置；音乐数据纳入现有原子事务、恢复日志、清理及加密 WebDAV 备份/恢复。页面刷新复用卡片与图表节点。

Adds opt-in QQ Music / NetEase Cloud Music statistics through read-only Windows SMTC: detected playback duration, configurable qualified-play threshold (30 seconds by default), current sessions, song/artist rankings, daily/weekly/monthly trends, player filters, optional cross-player merging and CSV export. Bilingual Music views support both themes and reuse cards/charts during refresh. Conservative timing excludes pauses, seeks and observation gaps; temporary pauses retain session identity. Only minute aggregates are saved. No accounts, cookies, lyrics, audio or private files are read, and players are never controlled or injected. Additive schema 9 preserves existing statistics and integrates music with recovery, clearing and encrypted WebDAV archives.

## 安装与升级 / Install and upgrade

- 安装版：`PulseTrace-Setup-v0.8.0-x64.exe`；便携版：`PulseTrace-v0.8.0-x64.zip`；两平台附件及 SHA-256 一致。
- 从托盘完全退出旧程序再升级，保留 `data`；便携版完整解压。需要 Microsoft Edge WebView2 Evergreen Runtime；音乐接口需要 Windows 10 1809 或更新系统。
- 升级前自动生成一致性数据库备份；旧程序不能直接打开已升级的 schema 9，请使用兼容备份降级。
- 在“设置 → 监测 → 音乐”主动启用播放器，并开启主监测开关；默认不采集音乐信息。

Quit the old tray process before upgrading and retain data. Extract the complete portable ZIP. WebView2 Evergreen Runtime is required; SMTC needs Windows 10 1809 or later. A consistent pre-migration backup is retained. Older binaries must use compatible backups rather than open schema 9 directly. Enable Music in Settings → Monitoring and turn on the main monitoring switch.

## 验证与限制 / Validation and limits

- 已完成音乐状态机、SQLite、恢复、加密归档和前端状态测试，以及双语/双主题原生 WebView2 自检；发布流程执行 Release/Debug 构建、完整 CTest、中英安装向导、隔离安装/升级/卸载/重装、旧布局及便携包校验，实际结果以本版验证回执为准。
- 本机 QQ 音乐的标题、歌手、Playing 状态及时间线可读，正式采集模块生成有效内存聚合；未发现网易云会话，其真实客户端兼容性未验证。完整真实暂停/循环/拖动/多播放器和锁屏/休眠场景仍需客户端验收，模拟测试不替代实机验证。
- SMTC 不提供稳定歌曲 ID 或 seek/loop 标志；仅能识别观测到的同曲结尾→开头循环，短循环和观测间断可能少计。统计代表检测到的播放时长，不保证用户实际听到声音。身份字段缺失时保守限制合并。
- 独立音乐探针仅作 15 秒资源短采样，不代表全应用或长期性能结论；未重新开展真实校园网计费、长期后台或云服务验收。
- 安装器无发行者代码签名，更新后仍需手动确认安装；自动执行下载的 EXE 保持禁用。

Music timeline, SQLite/recovery, encrypted-archive and frontend tests and bilingual/theme native UI checks are covered. The release pipeline runs Release/Debug builds and full CTest, isolated installer lifecycles, legacy-layout and portable checks; version-specific receipts record actual results. QQ metadata and in-memory collection work locally. No NetEase session was available: real NetEase compatibility and complete player/power transitions remain unverified, with simulated state coverage only. SMTC has no stable song ID or explicit seek/loop marker; short or unobserved loops may be undercounted. Detected Playing time is not a claim of audible listening. A 15-second isolated probe does not establish full-app or long-term resource limits. Real campus billing and external cloud acceptance are not newly validated. Installers are unsigned and require manual installation; automatic EXE execution stays disabled.
