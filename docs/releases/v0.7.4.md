# PulseTrace 0.7.4

Windows 10/11 x64 / 2026-11-09

## 更新 / Changes

- 修复校园网通信字段白名单遗漏新增计费确认、进位、流量范围和账期元数据，导致设置无法保存的问题；补齐合法字段并复用核心校验，非法参数仍拒绝。
- 设置页只读计算与 Dashboard/Network 统一使用保存成功的规则，保存失败的草稿不再显示为生效结果；保存后及时更新计算及进度，重启保留规则。
- 区分账期缺失或过期、原始读数待确认与真实网页结构失效，不再把账期问题误报为页面结构变化。不放宽计费确认条件，不显示虚假百分比。
- 保留旧规则、SQLite schema 8、历史数据、1024/1000 换算、单价基准和其他监测及加密备份功能；失败不覆盖上次有效规则或快照。

Fixes rejected campus billing metadata in the native message bridge. Settings calculations now use the same saved rules as Dashboard/Network, and failed drafts no longer appear effective. Billing confirmation, unconfirmed readings and actual webpage structure failures have distinct messages. Existing rules, schema-8 history, unit conversion and other monitoring/backup features remain compatible.

## 安装与升级 / Install and upgrade

- 安装版：`PulseTrace-Setup-v0.7.4-x64.exe`；便携版：`PulseTrace-v0.7.4-x64.zip`。GitHub/Gitee 使用相同五个附件及 SHA-256 校验文件。
- 从托盘完全退出旧程序，安装到原目录并保留 `data`，无需先卸载。便携版完整解压至新目录后迁移原 `data`，不要只替换 EXE。需要 Microsoft Edge WebView2 Evergreen Runtime。
- 升级后重新确认此前未保存的计费设置，无需清理数据库。保留升级前备份，低于 schema 8 的旧版本不应打开已升级数据库。账期、协议、上下行和资费口径仍须依据校方说明确认。

Quit the old tray process and retain existing data when upgrading. Extract the complete portable archive before migrating data. WebView2 Evergreen Runtime is required. Confirm previously unsaved billing settings again after upgrading; no database reset is needed. Keep a backup and do not open schema-8 data with incompatible older versions. School billing semantics still require confirmation.

## 验证范围 / Validation scope

- 修复开发阶段 Release/Debug 完整构建及各 32/32 CTest 通过，覆盖真实消息解析器保存、非法参数拒绝、失败保留、重启恢复和设置与概览一致性。
- 原生 Settings/Dashboard/Network 隔离自检通过，覆盖中英双语、深浅主题、800×600 DIP、九种概览状态及真实 WebView2 元数据通信；仅使用合成数据，不改动用户数据库。
- 发布准备重新执行双配置完整构建测试、中英安装向导、独立 AppId 安装/升级/卸载/重装、旧布局和便携包校验；验证回执绑定本版干净源码提交及附件哈希。
- 本轮未重新实测真实校园网账期、上下行、免费抵扣或最终资费。真实跨期、长期断网/锁屏/休眠恢复、独立流量计量及真实坚果云异机恢复仍需外部验收；安装包未配置发行者代码签名。

Both configurations passed all 32 development tests, including the actual native parser, persistence, failure preservation and restart. Native UI checks cover both locales/themes, nine states and the real WebView2 metadata bridge with synthetic data. Release preparation validates builds, installer lifecycles, legacy layouts and the portable package against the clean source commit. Live school billing semantics, long-term recovery, independent traffic accuracy and live cross-device Jianguoyun restore remain externally unverified. Installers have no publisher code signature.
