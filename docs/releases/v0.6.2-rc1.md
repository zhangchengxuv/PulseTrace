# PulseTrace 0.6.2-rc1

Windows 10/11 x64 本地修复候选版 / Local fix candidate

## 修复 / Fixes

- 修复校园网新增字段（包括“已用免费流量”）被旧消息白名单拒绝、错误回包无法关联请求而显示超时的问题。11 个字段使用同一协议列表；参数错误立即反馈。
- 支持字段名称与数值分列的门户布局，提供同一视觉行的临近数值候选，确认后重读数值元素。含义不明确的流量标签仍不参与自动计费。
- 版本号改为 0.6.2-rc1，便于与不含上述修复的 v0.6.1 发布包区分。旧安装包不会随源码更新自动改变。

Fixes timeouts for the campus picker's newer fields by sharing the full 11-field allowlist and correlating validation errors with their requests. Separate label/value columns now produce low-confidence suggestions requiring confirmation. Ambiguous traffic counters remain unknown.

## 升级与范围 / Upgrade and scope

- 这是本地候选包，未创建 Tag 或 GitHub/Gitee Release。安装版为 `PulseTrace-Setup-v0.6.2-rc1-x64.exe`；便携版为 `PulseTrace-v0.6.2-rc1-x64.zip`。
- 从托盘退出旧程序，运行新安装包并保留原安装目录及 `data`。不需要卸载或删除数据。便携版完整解压后运行，勿仅替换前端脚本。
- 已有统计、校园网规则及数据库 schema 保持兼容。实测门户可识别余额，全部字段可打开并准备点选；真实数值点击、流量口径、学校官方接口与长期认证恢复仍需人工验收。

Exit the old tray process and install into the existing directory, keeping its `data` folder. Uninstalling or deleting data is unnecessary. Portable users must extract the complete archive. This candidate has no public Release or tag; existing published v0.6.1 assets remain unchanged.
