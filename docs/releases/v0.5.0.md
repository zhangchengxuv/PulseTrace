# PulseTrace 0.5.0

Windows 10/11 x64 正式版 / Stable release

## 新增与改进 / Changes

- 校园网字段支持自动识别、网页元素映射、手动输入、受限公式和不使用。新增免费总额度、免费剩余、已用免费、可消费余额及付费已用字段。
- 手动值和公式按门户保存，不会被网页刷新覆盖。旧选择器规则自动迁移为自动模式。
- 支持 B、KB、MB、GB、KiB、MiB、GiB 与金额单位；账期变化时手动流量值可要求重新确认。
- 新增免费剩余、资金可使用流量、总可用流量和可信进度计算。单价为零、缺字段、除零或循环引用时保持无法计算。
- 安全公式仅允许数字、字段名、括号、加减乘除及 `min`、`max`、`abs`，不执行脚本。
- Dashboard/Network 区分网页实时值、手动值、公式值、本地计算值和未知值。
- 修复页面切换前清空共享内容区导致的空白/闪烁；页面现在离屏构建后一次替换，并恢复各页面滚动位置。

PulseTrace 0.5.0 adds flexible campus field modes, safe calculations for free and balance-funded data, billing-cycle handling and explicit data-source labels. Page navigation now builds content off-screen before a single shared-region replacement, eliminating blank transition frames.

## 限制 / Limitations

- 自动刷新仍只在用户打开的门户窗口存在时运行。
- 通用识别不能覆盖所有高校；Shadow DOM、Canvas、跨域 iframe 内容和学校专用接口仍可能需要 SiteAdapter。
- 未访问真实高校账号；真实登录、MFA、学校改版及长期刷新仍需人工验收。

Automatic refresh still runs only while the user-opened portal window exists. Generic recognition cannot cover every institution or service. No real university account was accessed during validation.
