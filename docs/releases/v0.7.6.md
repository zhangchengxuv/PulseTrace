# PulseTrace 0.7.6

Windows 10/11 x64 / 2026-11-09

## 更新 / Changes

- 修复 GitHub 更新 API 限流被误报为无法连接；分别提示请求额度耗尽、访问拒绝及其他来源错误，支持切换自动来源后重试。
- 限流时读取同仓库公开版本订阅，版本提示可用；安装包元数据不足时要求打开发布页面确认，不自动下载或安装。
- 当前及更旧版本不再额外请求校验文件，重试时清除旧状态。不修改系统代理、采集、SQLite 或云备份。

Handles GitHub API rate limits with specific source errors and an explicit retry using automatic sources. A bounded public release feed can identify versions during rate limits; incomplete installer metadata requires manual confirmation on the release page. Installed versions no longer fetch unnecessary checksums. Capture, databases, cloud backups and system proxy settings remain unchanged.

## 安装与升级 / Install and upgrade

- 安装版：`PulseTrace-Setup-v0.7.6-x64.exe`；便携版：`PulseTrace-v0.7.6-x64.zip`。两平台使用相同附件和 SHA-256。
- 从托盘完全退出旧程序后升级，保留现有 `data`；便携版完整解压。需要 Microsoft Edge WebView2 Evergreen Runtime，保留 schema 8 和原配置。

Quit the old tray process before upgrading and retain existing data. Extract the complete portable archive. WebView2 Evergreen Runtime is required; schema-8 databases and configuration are preserved.

## 验证与限制 / Validation and limits

- 发布流程执行 x64 Release/Debug 构建测试、隔离安装/升级/卸载/重装、旧布局及便携包校验，实际结果以本版验证回执为准。
- 更新修复已通过原生受控传输及双语界面状态测试；真实 GitHub 元数据查询成功。Gitee 更新接口直连仍可能失败；限流回退未制造真实限流，未验证真实新版本自动安装。
- 安装包无发行者代码签名，自动执行安装器仍禁用；可手动安装。未重新开展长期性能及真实校园网计费验收。

The release pipeline checks x64 Release/Debug builds and tests, isolated installer lifecycles, legacy layouts and portable artifacts; the version-specific validation receipt records actual results. Updater fixtures and bilingual UI states pass, and live GitHub metadata succeeds. Direct Gitee API connectivity can still fail. Feed fallback uses controlled rate-limit fixtures; live unattended installation, long performance runs and real campus billing are not newly validated. Installers are unsigned; automatic execution remains disabled.
