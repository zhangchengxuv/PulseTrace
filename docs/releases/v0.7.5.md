# PulseTrace 0.7.5

Windows 10/11 x64 / 2026-11-09

## 更新 / Changes

- 调整鼠标 SVG 外壳、左右键、滚轮和两个侧键的比例、圆角与间距，移除滚轮中央文字及缺测虚线；深浅主题均使用低对比度空闲区域。
- 有记录的按键沿用真实点击次数与 Arctic 热力配色，保留次数悬停、键盘焦点和 Mouse5 前进 / Mouse4 后退映射。
- 包含此前已提交的全局文案精简：复杂口径和校园网公式移至 Tooltip 或折叠详情，保留估算、数据质量和安全提示。

Refines the mouse silhouette, mirrored main buttons, wheel and side buttons. Removes the wheel text and dashed outlines, with theme-aware idle fills. Click counts, Arctic heat colors, hover/focus details and Mouse5 forward / Mouse4 back remain available. Includes the previously committed UI copy simplification.

## 安装与升级 / Install and upgrade

- 安装版：`PulseTrace-Setup-v0.7.5-x64.exe`；便携版：`PulseTrace-v0.7.5-x64.zip`。两平台使用相同文件及 SHA-256 校验附件。
- 完全退出旧托盘程序后升级，保留原 `data`。便携版完整解压，勿只替换 EXE。需要 Microsoft Edge WebView2 Evergreen Runtime。保留 schema 8、现有配置和用户数据。

Quit the old tray process before upgrading and retain existing data. Extract the complete portable archive; WebView2 Evergreen Runtime is required. Existing schema-8 databases and configuration remain unchanged.

## 验证范围 / Validation scope

- 按本次要求，仅执行 Windows x64 Release 构建及安装版/便携版产物检查（版本、文件清单与 SHA-256）。不运行完整测试、Debug 构建、UI 回归、安装升级生命周期或长时间性能测试。
- 本轮鼠标视觉与交互的实机效果、中英双语/深浅主题运行表现未重新实测，不标记为已验证。未修改采集或 SQLite。安装包无发行者代码签名。

This release is limited to the requested x64 Release build and artifact checks (versions, file manifests and SHA-256). Full tests, Debug builds, UI regression, installer lifecycles and long performance runs were not executed. Mouse appearance/interactions and runtime locale/theme behavior have not been revalidated; no claims of such validation are made. Capture and SQLite logic are unchanged. Installers have no publisher code signature.
