# PulseTrace v0.2.0-rc2

Windows x64 预发布候选版。完整解压 ZIP 后运行 PulseTrace.exe，使用系统 Evergreen WebView2 Runtime；无需浏览器端口、Node.js 后台或 Npcap 驱动。

## 本版功能

- 深浅蓝主题、响应式六页仪表盘、正式应用图标；原生标题栏和窗口按钮与界面融合。
- ANSI 104 键盘布局、Arctic 自定义连续色图、平方根归一化、点击详情和时间范围查询。
- 键盘/鼠标聚合计数、托盘后台监测，关闭窗口释放 WebView2，默认启动暂停。
- 网络接口总上传/下载、连接历史、物理接口 ETW IPv4/IPv6 上传/下载观测及质量诊断。
- 月度累计六项用量，按自然月独立保存 SQLite 和可读 JSON，可查看路径和打开文件夹。
- 保留原 SQLite/配置、批量保存、历史补档与导出；分钟明细保留期不删除月度集合。

## 安装与升级

可以直接便携运行，或手动执行包内 tools/install.ps1 安装并创建快捷方式。升级前从托盘完全退出旧版，再安装到原目录；安装器保留 data。首次新目录启动默认暂停，不会自动启用自启动。月库位于程序目录 data/network-months/YYYY-MM.sqlite3 和 YYYY-MM.json。

## 实测

- Release / Debug 各 7/7 CTest；18,849 项前端、56 项鼠标、152 项报文、65 项产品、19 项月度检查通过。
- 五档尺寸、深浅主题、六页面、原生窗口与托盘生命周期、独立解压和安装升级保留数据检查通过。
- ZIP 不包含本机监测数据库、用户配置、抓包或日志；附带 SHA-256 校验文件。

## 已知限制

- IPv4/IPv6 是真实观测，但一般流量存在长度异常拒收，仍标记为“不完整观测”，完整精确计量尚未验收，不能等同校园网账单。旧总量历史不估算拆分协议族。
- 独立抓包对照、有线、TUN/代理/DIRECT 专项、高吞吐与 24/72 小时测试仍待完成。没有自动安装驱动或修改网络配置。
- Windows 10、其他 DPI/跨屏、真实鼠标操作及全键硬件验收仍待进行。Windows 11 最大化按钮悬停 Snap Layout 弹层未实现。
