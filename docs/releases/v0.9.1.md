# PulseTrace v0.9.1

## 更新 / Changes

- **IPv4／IPv6 实时速率** · 修复已退出的 PulseTrace 实例遗留 ETW 会话阻塞分协议速率的问题。新会话独立接收事件，并回收已退出实例的实时会话。网络页区分等待采样、采样不完整和实测零值。分协议观测不可用时，接口总速率仍可显示。
- **Windows 后台启动** · 登录时若托盘尚未就绪，程序会重试添加图标，等待最长 30 秒后再回退到主窗口。重复启动保持在后台。启动日志记录托盘就绪或主窗口回退，设置页说明「启动时监测」如何控制采集。

- **Live IPv4 and IPv6 rates** · Fixes a case where an abandoned PulseTrace ETW session could block live per-protocol rates. New sessions receive events independently and reclaim real-time sessions left by terminated instances. The Network page distinguishes pending or incomplete samples from observed zero. Interface rates remain available when per-protocol observation is unavailable.
- **Windows background startup** · PulseTrace retries adding its tray icon when the tray is unavailable at sign-in. It opens the main window if the tray is still unavailable after 30 seconds. Duplicate background launches leave the window closed. The startup log records the outcome, and Settings explains how Monitor on launch controls collection.

## 安装与升级 / Install and upgrade

- 安装版为 `PulseTrace-Setup-v0.9.1-x64.exe`，便携版为 `PulseTrace-v0.9.1-x64.zip`。请使用 `SHA256SUMS.txt` 校验下载。升级前从托盘完全退出旧版并保留 `data` 目录。便携版需完整解压，程序依赖 Microsoft Edge WebView2 Evergreen Runtime。
- 从 v0.9.0 升级继续使用 **SQLite schema 9**，无需数据库结构迁移。

- Use `PulseTrace-Setup-v0.9.1-x64.exe` for installation or `PulseTrace-v0.9.1-x64.zip` for portable use. Verify downloads against `SHA256SUMS.txt`. Quit the previous version from the tray and keep the `data` directory. Extract the complete portable ZIP. Microsoft Edge WebView2 Evergreen Runtime is required.
- Upgrading from v0.9.0 retains **SQLite schema 9** and requires no schema migration.

## 验证与限制 / Validation and limits

- Windows x64 发版验证覆盖 Release 与 Debug 构建及各 38 项 CTest、原生 WebView2、中英文安装向导、隔离安装与升级、旧布局和便携版。
- 真机短时探测在回收残留会话后收到 IPv4／IPv6 四个方向的计数。隔离测试覆盖后台托盘启动和重复启动。真实注销后重新登录、最高权限计划任务触发、持续流量的独立字节对照仍待复测。

- Windows x64 release validation covers Release and Debug builds with 38 CTest cases each, native WebView2, English and Chinese installer wizards, isolated installs and upgrades, the legacy layout, and the portable ZIP.
- A short test on a physical interface observed all four IPv4 and IPv6 directions after orphan recovery. Isolated tests covered tray startup and duplicate launches. Real sign-out and sign-in, the highest-privilege logon task, and independent byte comparisons under sustained traffic remain unverified.
