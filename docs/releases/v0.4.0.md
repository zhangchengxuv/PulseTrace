# PulseTrace 0.4.0

Windows 10/11 x64 正式版 / Stable release

## 新增 / Added

- 通用校园网门户监控，默认关闭。可配置门户 URL、登录重定向域名、刷新间隔与自定义单价。
- 独立 WebView2 登录会话；不保存密码、Cookie 或 Token。主框架、子框架和新窗口只允许用户明确配置的域名。
- 通用 DOM 识别支持中英文关键词、表格、邻近字段和属性，转换 B、KB、MB、GB、GiB 与金额单位；SPA 在打开的门户窗口中有限次数重试。
- 候选结果显示原始值、类型和置信度。低置信度、冲突或改版不会静默覆盖已确认规则；用户可预览确认，或点击网页元素手动映射。
- 每个门户保存独立规则，支持重新识别、编辑和删除。Dashboard/Network 显示余额、已用/剩余、额度、真实费用、本地估算及质量状态。
- SQLite Schema v7 保存门户聚合快照，升级前自动备份；已有键鼠、网络、应用使用、排行、月档、配置和历史保留。
- 发布附件提供安装包、便携 ZIP 及顶层 `SHA256SUMS.txt`，两个安装产物的校验值同时以独立 sidecar 和汇总清单提供。

PulseTrace 0.4.0 adds optional generic campus-portal monitoring. An isolated WebView2 session handles sign-in while local DOM analysis proposes field mappings with confidence. Users confirm recognized fields or click elements to map them manually. Confirmed rules are stored per portal and structured snapshots use schema v7.

Release assets include the installer, portable ZIP and a top-level `SHA256SUMS.txt`.

## 安全与限制 / Security and limits

- 不扫描局域网，不绕过验证码或访问限制，不读取无关页面、密码或完整浏览历史；网页不能调用原生特权接口。
- 自动刷新只在用户打开的门户窗口存在时运行，避免后台长期保留第二个 WebView2。关闭窗口后需再次打开同步。
- 通用 DOM 识别不保证覆盖所有高校。无法确认时保持未知，不以物理流量推算余额。`http://202.204.48.66` 只是可选测试占位地址。
- 本地估算费用与门户真实费用分开。本轮没有访问或验证任何真实高校账号；真实登录、MFA、学校改版和长期刷新仍需人工验收。

Automatic refresh runs only while the user-opened portal window exists, avoiding a persistent background WebView2. Generic DOM recognition cannot cover every institution. Unknown values remain unknown. No real university account was accessed during validation.
